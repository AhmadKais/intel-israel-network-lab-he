## חלק 1 — קודם מבינים (בשפה פשוטה)

### 1.1 למה מגדילים רק בסוף?
משרד החינוך דורש **6 מחלקות × לפחות 8 מחשבים** בכל סניף (דרישה 20.2). הבנייה עם 2 מחשבים לכל מחלקה
הפכה את המעבדה למהירה וקלה לקריאה. מכיוון שעכשיו הכול אוטומטי (DHCP, ‏SLAAC, ‏port-security ‏sticky),
הוספת מחשבים היא רק לגרור, לחבר כבל ולשנות שם.

### 1.2 איך דואר אלקטרוני עובד ב-Packet Tracer
- **שרת הדואר** מחזיק תיבות דואר (`eng1@intel.lab`) — כמו סניף דואר עם תאי דואר.
- **לקוח הדואר** במחשב שולח דואר לשרת (SMTP) ואוסף את הדואר שלו (POP3).
- הלקוח מוצא את השרת לפי **שם** (`mail.intel.lab`) ‏←‏ בגלל זה ה-DNS היה צריך לעבוד קודם.

חיפה וירושלים משתמשות בשרת הדואר שב-DMZ (ירושלים דרך ה-VPN). קריית גת משתמשת בשרת דואר IPv6 משלה
(`kg.intel.lab`).

### 1.3 בדיקה = הוכחה
הבוחן נותן ציון על מה שאתם יכולים **להראות**. כל דרישה צריכה בדיקה שאפשר להריץ בזמן אמת וצילום מסך
בספר הפרויקט.

## חלק 5 — סבב הקשחה אחרון
בכל נתב ומתג הריצו:
```
show running-config | include hostname|banner|enable secret|service password|ip ssh|logging|ntp server
```
כל אחד חייב להציג: ‏hostname לוגי, ‏banner, ‏`enable secret`, ‏`service password-encryption`, ‏SSH v2,
‏logging host, שרת NTP. בדקו גם `show running-config | section vty` ‏←‏ `transport input ssh` +
‏`access-class`. תקנו את מה שחסר, ואז שמרו **כל** מכשיר (`copy run start`, ‏`write memory` ב-ASA).

## אתגר סופי — מגינים על הפרויקט
הבוחן שואל "למה?" על כל בחירה. ענו בקול בלי דפים:
1. למה ה-area של בניין C לא מחובר ל-area 0, ומה ה-virtual link עושה?
2. למה ה-ASA לא עושה NAT בתכנון הזה?
3. למה GRE over IPsec ולא IPsec רגיל?
4. למה ה-HSRP active הוא תמיד גם ה-STP root של אותו VLAN?
5. מה קורה לירושלים אם R-JLM-EDGE מת? איך הייתם מתקנים?

<details dir="rtl"><summary>תשובות קצרות</summary>

1. כדי לעמוד בדרישות 8/22.16 ולהראות את הכלל "כל area חייב לגעת ב-area 0". ה-virtual link הוא חיבור
   לוגי של area 0 דרך area המעבר 2, בין B-DIST ‏(ABR 0/2) ל-C-DIST ‏(ABR 2/3).
2. כדי שכתובות פרטיות יעברו את ה-ASA בלי שינוי — נקודת NAT אחת (נתב הקצה) פשוטה יותר, וה-VPN רואה את
   כתובות ה-10.x האמיתיות.
3. ה-static NAT של שרת ה-web היה מתרגם את התשובות שלו ב-VPN לפני ההצפנה; תעבורה דרך ממשק מנהרת GRE
   (שהוא לא ממשק NAT) לא מתורגמת. ‏GRE גם מאפשר בעתיד להעביר פרוטוקולי ניתוב דרך המנהרה.
4. כדי שהדרך לשער תהיה קצרה — אחרת מסגרות עוברות בקישור שבין מתגי ה-distribution בלי סיבה.
5. ירושלים מאבדת את האינטרנט ואת ה-VPN (נקודת כשל יחידה). פתרון: נתב קצה שני + קישור שני לספק, ‏HSRP
   ביניהם, ומנהרה שנייה לחיפה.
</details>

**בקול**, ואז הראו את התשובה בפרויקט שלכם — לא בדוגמה. כסו את התשובה, ענו בעצמכם, ורק אז
פתחו והשוו.

★1–★3 = שאלה ממאגר השאלות של משרד החינוך (רמת קושי 1–3).
◆ = לא במאגר, אבל בוחנים שואלים אותה לעיתים קרובות.

**1. ★3 הראה לי את טבלאות כתובות ה-IP שלך והסבר את התוכנית.**

<details dir="rtl"><summary>תשובה</summary>

השתמשו בספר הפרויקט: בלוק ראשי ‏←‏ בלוקים לכל אתר ‏←‏ areas ‏←‏ ‏VLANים ‏←‏ קישורים / ‏loopbacks, ולמה
(קריאוּת, סיכום נתיבים, גדילה).

**איפה מראים:** `my-project/plan.md`, ספר הפרויקט
</details>

**2. ◆ תאר את הדרך של חבילה ממחשב בסניף לשרת ה-web ב-DMZ.**

<details dir="rtl"><summary>תשובה</summary>

המחשב ‏←‏ השער שלו (HSRP ‏‎`.1`) ‏←‏ פרוטוקול הניתוב של הסניף ‏←‏ נתב הקצה (נתיב ברירת מחדל סטטי, ‏NAT) ‏←‏
ה-WAN / מנהרת ה-VPN ‏←‏ נתב הקצה של המטה ‏←‏ ‏ASA ‏(ACL, רמות אבטחה) ‏←‏ שרת ה-DMZ. ציינו את המכשיר ואת
ההחלטה בכל קפיצה.

**איפה מראים:** `tracert <server IP>`‎ מהמחשב
</details>

**3. ◆ איזו דרישה ממומשת איפה?**

<details dir="rtl"><summary>תשובה</summary>

עברו על רשימת משרד החינוך והצביעו על המכשיר ועל פקודת ה-`show` של כל אחת. הכינו את הרשימה הזו מראש
בספר הפרויקט.

**איפה מראים:** `docs/requirements-matrix.md`, הגרסה שלכם
</details>

## 🔁 עושים שוב — בלי המדריך

הבוחן יכול לבקש מכם להגדיר משהו שוב, מולו. תצליחו רק אם עשיתם את זה **בלי המדריך** לפני כן.
עשו את התרגיל הזה בפרויקט שלכם:

החזרה הגנרלית — עשו אותה פעמיים לפני הבחינה:
1. בקשו מחבר לכיתה לבחור 5 דרישות כלשהן; לכל אחת, הראו את ההגדרות ופקודת `show` שמוכיחה שהיא עובדת,
   והסבירו כל שורה — **‏2 דקות לכל דרישה**.
2. בקשו מחבר לכיתה לקלקל משהו בעותק של הקובץ שלכם (לכבות ממשק, למחוק שורה). מצאו את זה עם פקודות
   `show` ותקנו — **‏10 דקות**.

## 👩‍🏫 הערות למורה
- **שיעור 1:** הגדלה (בזוגות: כל זוג מגדיל סניף אחד) + ‏Clusters לצילומי מסך נקיים.
- **שיעור 2:** שרתי דואר ולקוחות; בדיקת הדואר דרך ה-VPN.
- **שיעור 3:** תוכנית הבדיקות — התלמידים מריצים את כל 24 הבדיקות ואוספים צילומי מסך.
- **שיעור 4:** ספר הפרויקט — עוברים על הטיוטה פרק אחרי פרק; בחינה בעל פה לדוגמה עם שאלות האתגר הסופי.
- **בדיקה לפני הגשה:** אסור ששני תלמידים יגישו את אותו פרויקט — החברה, הערים, השמות ותוכנית הכתובות
  של כל תלמיד חייבים להיות שלו.
