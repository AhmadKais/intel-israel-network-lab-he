# מילון מונחים — כל מונח בשפה פשוטה

מסודר לפי השלב שבו פוגשים את המונח בפעם הראשונה.

## בסיס (שלב 00)

<div dir="rtl">

| מונח | משמעות פשוטה |
|---|---|
| **רשת (Network)** | מכשירים שמחוברים כך שהם יכולים להחליף נתונים |
| **מכשיר קצה (End device)** | מכשיר שאנשים משתמשים בו: מחשב, מחשב נייד, מדפסת, טלפון |
| **מתג (Switch)** | מחבר מכשירים באותה רשת מקומית; מוסר לפי כתובת MAC |
| **נתב (Router)** | מחבר רשתות שונות; בוחר את הדרך לפי כתובת IP |
| **מתג שכבה 3 (Layer-3 switch)** | מתג שיודע גם לנתב |
| **שרת (Server)** | מחשב שנותן שירות (web, דואר, ‏DNS, ‏DHCP…) |
| **כתובת MAC** | המזהה החומרתי של כרטיס רשת. לא משתנה אף פעם. כמו מספר תעודת זהות |
| **כתובת IP** | הכתובת הלוגית של מכשיר ברשת. כמו כתובת של בית |
| **מסיכת רשת / prefix** | אומרת איזה חלק של ה-IP הוא הרשת ("הרחוב") ואיזה הוא המכשיר ("הבית") |
| **שער ברירת מחדל (Default gateway)** | הנתב שמכשיר שולח אליו תעבורה כשהיעד ברשת אחרת |
| ‎**‏Ping** | הודעת בדיקה: "אתה שם?" — תשובה מוכיחה שהדרך עובדת בשני הכיוונים |
| ‎**‏ARP** | "למי יש את ה-IP ‏X? תגיד לי את ה-MAC שלך" — כך מכשיר מוצא את ה-MAC של IP |
| **טבלת כתובות MAC** | הרשימה של המתג: איזה MAC נמצא באיזה פורט |
| ‎**‏Broadcast** | הודעה שנשלחת לכולם ברשת המקומית |
| ‎**‏IOS / ‏CLI** | מערכת ההפעלה של Cisco / ממשק הטקסט שבו מקלידים פקודות |
| ‎**‏Running-config** | ההגדרות שפעילות עכשיו (בזיכרון — נמחקות באתחול) |
| ‎**‏Startup-config** | ההגדרות השמורות שנטענות בהדלקה (`copy run start` שומר אליהן) |

</div>

## התצוגות של Packet Tracer (שלבים 00, ‏09, ‏12–16)

<div dir="rtl">

| מונח | משמעות פשוטה |
|---|---|
| **תצוגה לוגית (Logical)** | מפת הרשת ב-Packet Tracer: מי מחובר למי. בונים ומגדירים כאן |
| **תצוגה פיזית (Physical)** | איפה המכשירים באמת נמצאים: Intercity ‏←‏ עיר ‏←‏ בניין ‏←‏ ארון תקשורת ‏←‏ rack |
| ‎**Intercity** | הרמה העליונה של התצוגה הפיזית — מפת הארץ עם כל הערים |
| **ארון תקשורת (wiring closet)** | החדר בבניין שבו המתגים והנתבים עומדים בארונות rack (בעולם האמיתי: MDF = הארון הראשי, IDF = ארון בקומה) |
| ‎**‏Cluster** | הרבה מכשירים שמוצגים כסמל **אחד** בתצוגה הלוגית — רק הציור משתנה |
| **אתר (site)** | מיקום אחד של החברה — בקורס הזה, עיר אחת (חיפה, ירושלים, קריית גת) |

</div>

## כתובות (שלב 01)

<div dir="rtl">

| מונח | משמעות פשוטה |
|---|---|
| **כתובות פרטיות** | ‏10.x, ‏172.16–31.x, ‏192.168.x — לשימוש בתוך ארגונים, לא באינטרנט |
| **רשת משנה (Subnet)** | רשת אחת ("רחוב") — למשל 10.10.16.0/24 |
| **‏‎/24, ‏‎/30, ‏‎/32…** | כמה ביטים הם חלק הרשת. מספר גדול יותר = רשת קטנה יותר |
| **כתובת רשת (Network address)** | הכתובת הראשונה של רשת משנה (השם שלה) — אי אפשר לתת אותה למכשיר |
| **כתובת broadcast** | הכתובת האחרונה של רשת משנה ("כולם") — אי אפשר לתת אותה למכשיר |
| **כתובות היררכיות** | בלוק גדול ‏←‏ בלוקים קטנים יותר ‏←‏ בלוקים עוד יותר קטנים, כמו מדינה ‏←‏ עיר ‏←‏ רחוב |
| **סיכום נתיבים (Route summarization)** | מפרסמים נתיב גדול אחד במקום הרבה קטנים |
| ‎**‏Loopback** | ממשק וירטואלי שאף פעם לא נופל — משמש כמזהה של המכשיר |

</div>

## מיתוג (שלבים 02–04)

<div dir="rtl">

| מונח | משמעות פשוטה |
|---|---|
| ‎**‏VLAN** | רשת וירטואלית נפרדת ("חדר") בתוך מתג |
| **פורט access** | פורט למכשיר קצה אחד, ב-VLAN אחד |
| ‎**‏Trunk** | קישור אחד שנושא הרבה VLANים, עם תגיות |
| **תגית 802.1Q** | ה"מדבקה" על מסגרת שאומרת לאיזה VLAN היא שייכת |
| ‎**‏Native VLAN** | ה-VLAN היחיד שעובר ב-trunk בלי תגית (אנחנו משתמשים ב-VLAN 998 שלא בשימוש) |
| ‎**‏DTP** | משא ומתן אוטומטי על trunk — אנחנו מכבים אותו |
| ‎**‏VTP** | משתף את רשימת ה-VLANים ממתג server למתגי client |
| ‎**‏VTP revision number** | מספר הגרסה של רשימת ה-VLANים — הגבוה ביותר מנצח |
| **הקשחה (Hardening)** | הגדרות אבטחה בסיסיות: סיסמאות, ‏banner, זמני ניתוק, פורטים לא בשימוש כבויים |
| ‎**‏Banner ‏(MOTD)** | אזהרה משפטית שמוצגת לפני ההתחברות |
| **‏VLAN חניה (Parking VLAN)** | ‏VLAN לא בשימוש שאליו מעבירים (ומכבים) את כל הפורטים שלא בשימוש |
| **לולאה (Loop)** | שתי דרכים או יותר בין מתגים — broadcasts מסתובבים לנצח, אלא אם STP חוסם אחת |
| ‎**‏STP ‏(Spanning Tree)** | חוסם קישורים כפולים כדי למנוע לולאות; פותח אותם אם הקישור הפעיל נופל |
| ‎**‏Root bridge** | המתג ש"במרכז" עץ ה-spanning tree |
| ‎**‏EtherChannel** | כמה כבלים שמאוגדים לקישור לוגי אחד |
| ‎**‏PortFast / ‏BPDU Guard / ‏Root Guard** | תכונות STP לפורטים מהירים של מחשבים ולהגנה מפני מתגים זרים |

</div>

## בהמשך

<div dir="rtl">

| מונח | משמעות פשוטה | שלב |
|---|---|---|
| ‎**‏Inter-VLAN routing / ‏SVI** | ניתוב בין VLANים במתג שכבה 3 / הממשק הווירטואלי שלו לכל VLAN | ‎05 |
| ‎**‏HSRP** | שני נתבים חולקים כתובת שער וירטואלית אחת | ‎05 |
| ‎**‏DHCP** | נותן למכשירים את הגדרות ה-IP שלהם אוטומטית | ‎05 |
| ‎**‏Port-security / ‏DHCP snooping** | הגבלת מספר המכשירים בפורט / חסימת שרתי DHCP מזויפים | ‎06 |
| ‎**‏SSH** | התחברות מרחוק מוצפנת | ‎07 |
| ‎**‏OSPF / ‏area / ‏ABR** | פרוטוקול ניתוב / קבוצת נתבים / נתב בין areas | ‎08 |
| ‎**‏AAA / ‏TACACS+ / ‏Syslog / ‏NTP** | בדיקה מרכזית של התחברויות / הפרוטוקול שלה / יומנים מרכזיים / סנכרון שעון | ‎08, ‏11 |
| ‎**‏Virtual link** | חיבור לוגי שמצרף area מרוחק ל-area 0 | ‎09 |
| ‎**‏SSID / ‏WPA2** | שם רשת ה-WiFi / ההצפנה של WiFi | ‎10 |
| **חומת אש / ‏DMZ / ‏security level** | מסנן תעבורה / אזור השרתים / רמת האמון של ממשק ASA | ‎11 |
| ‎**‏BGP / ‏AS** | פרוטוקול הניתוב של האינטרנט / הרשת של ארגון אחד | ‎12 |
| ‎**‏NAT / ‏PAT** | תרגום כתובות פרטיות לציבוריות / הרבה משתמשים שחולקים IP ציבורי אחד | ‎12 |
| ‎**‏EIGRP / ‏collapsed core** | פרוטוקול הניתוב של Cisco / ‏core ו-distribution בשכבה אחת | ‎13 |
| ‎**‏IPv6 / ‏SLAAC / ‏OSPFv3** | כתובות של 128 ביט / כתובות IPv6 אוטומטיות / ‏OSPF ל-IPv6 | ‎14 |
| ‎**‏VPN / ‏IPsec / ‏GRE** | מנהרה פרטית דרך האינטרנט / הצפנה / מנהרה פשוטה | ‎15 |

</div>
