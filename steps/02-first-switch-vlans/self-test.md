# שלב 02 — בדיקה עצמית

<div dir="rtl">

> 🧪 עושים את הבדיקה הזאת **אחרי** שמסיימים את שלב 02, על הקובץ השמור `my-work/step02.pkt`.
> היא לוקחת בערך 15 דקות. כך יודעים שהעבודה באמת נכונה לפני שממשיכים.

</div>

## איך עובדים עם הבדיקה
1. עושים את הבדיקות **לפי הסדר**, מלמעלה למטה.
2. בכל בדיקה עושים את מה שכתוב בעמודה **מקלידים / עושים**, ומשווים את המסך לעמודה
   **חייבים לראות**. ‏❌ בעמודה "חייבים לראות" אומר שהבדיקה **חייבת להיכשל**. אם היא נכשלת, עברתם.
3. אם זה מתאים, מסמנים ☐ ‏←‏ ☑ (על דף, או בעותק שלכם של הקובץ).
4. אם זה לא מתאים, עושים את מה שכתוב בעמודה **אם לא**, ומריצים את אותה בדיקה שוב.
   לא מדלגים על בדיקה שלא עברה.
5. כל הסעיפים מסומנים ‏←‏ שלב 02 עובד. ממשיכים לשלב 03.

מקלידים את הפקודות ב-prompt ‏`SW-HFA-A-ACC1#`‎ (אחרי הכניסה ב-א1–א3). מספרי "M…" הם הפעולות
הבסיסיות ב-[docs/basic-moves.md](../../docs/basic-moves.md).

## 🛠 הפרויקט שלכם
מריצים את אותה בדיקה על מתג ה-access הראשון בפרויקט שלכם. מחליפים:

<div dir="rtl">

| בבדיקה | לוקחים מהתוכנית שלכם |
|---|---|
| ‎`SW-HFA-A-ACC1` | שם מתג ה-access שלכם |
| ‎`Intel Israel - AUTHORIZED ACCESS ONLY` | טקסט הבאנר שלכם |
| ‎‏`Intel#Con`, ‏`Intel#En4ble` | סיסמת הקונסולה וה-enable secret שלכם |
| ‏VLANים 10/20/30/99/110/120/998/999 וטווחי הפורטים שלהם | טבלת ה-VLANים ותוכנית הפורטים שלכם |
| ‎‏‎`10.10.16.x`, ‏‎`10.10.17.x` … | כתובות המחשבים שלכם |

</div>

הפרויקט שלכם עובר כשכל הבדיקות א1–א5, ב1–ב4, ג1–ג3 ו-ד1–ד2 מתאימות לערכים **שלכם**.
