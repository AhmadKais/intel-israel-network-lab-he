# 📘 כל הפקודות של הפרויקט

לפי סדר הסיפור: כל פקודה, מה היא עושה ולמה, ואיפה כותבים אותה בפעם הראשונה.

| ‎`hostname SW-S-MAIN` | נותן למכשיר שם, זה שרואים בשורת הפקודה. כך לא כותבים במכשיר הלא נכון. | [שיעור 1, משימה 4](../lesson-01/) |
| ‎`no ip domain-lookup` | שגיאת הקלדה לא נשלחת לחיפוש ב-DNS, ולכן לא מחכים אחרי כל טעות. | [שיעור 1, משימה 4](../lesson-01/) |

| ‎`service password-encryption` | מסתיר את שאר הסיסמאות ב-`show run`. חלש, אבל עדיף מטקסט גלוי. | [שיעור 1, משימה 4](../lesson-01/) |

| ‎`line console 0` | נכנסים להגדרות של פורט הקונסול (הכבל הכחול / לשונית CLI). | [שיעור 1, משימה 4](../lesson-01/) |

| ‎`logging synchronous` | הודעות מערכת לא חותכות את השורה שאתם כותבים. | [שיעור 1, משימה 4](../lesson-01/) |
| ‎`exec-timeout 10 0` | מנתק אחרי מספר כזה של דקות ושניות בלי הקלדה (10 דקות, 0 שניות). | [שיעור 1, משימה 4](../lesson-01/) |
| ‎`end` | יוצאים ישר ל-‎`#`‎, מכל עומק. | [שיעור 1, משימה 4](../lesson-01/) |
| ‎`copy running-config startup-config` | שומר את מה שבזיכרון לקובץ ההפעלה. בלי זה הפסקת חשמל מוחקת את העבודה. | [שיעור 1, משימה 4](../lesson-01/) |
| ‎`show run` | כל ההגדרות שפועלות עכשיו. | [שיעור 1, משימה 4](../lesson-01/) |

## פרק 2 — קירות בתוך המתגים

<div dir="rtl">

| פקודה | מה היא עושה, ולמה | פעם ראשונה |
|---|---|---|
| ‎`show vlan brief` | רשימת ה-VLAN והפורטים בכל אחד. פורטים של trunk לא מופיעים. | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`vtp domain SAKHNIN` | שם קבוצת ה-VTP. רק מתגים עם שם **זהה לגמרי** חולקים את רשימת ה-VLAN (אותיות גדולות משנות). | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`vtp password Osem#Vtp` | סוד משותף, כדי שמתג זר לא ישנה את ה-VLAN שלנו. חייב להיות זהה בכולם. | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`vtp mode server` | המתג הזה רשאי ליצור VLAN וללמד את האחרים. | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`vlan 10` | יוצר את ה-VLAN עם המספר הזה. המספר הוא מה שנוסע בתג. | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`name MANAGEMENT` | שם ל-VLAN, בשביל בני אדם. המתג עובד עם המספר. | [שיעור 2, משימה 1](../lesson-02/) |
| ‎`vtp mode client` | המתג הזה רק מקבל את הרשימה. `vlan 10` בו נדחה. | [שיעור 2, משימה 2](../lesson-02/) |
| ‎`show interfaces trunk` | אילו פורטים הם trunk, ואילו VLAN עוברים. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`shutdown` | מכבה את הפורט. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`interface range fa0/1 , fa0/3 - 8` | מגדיר כמה פורטים ביחד. שימו לב לרווחים סביב הפסיק והמקף. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport mode trunk` | הפורט מעביר את **כל** ה-VLAN, עם תג. בין מתגים ובין מתג לנתב. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`exit` | רמה אחת אחורה, למשל מפורט להגדרות כלליות. השורה הבאה שייכת לרמה העליונה. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`interface fa0/2` | בוחרים פורט. כל מה שמתחת חל עליו, עד `exit`. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport mode access` | הפורט שייך ל-VLAN אחד, למכשיר קצה אחד. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport access vlan 50` | לאיזה VLAN הפורט שייך. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport port-security` | **מפעיל** port security. בלי השורה הזו שלוש האחרות לא עושות כלום. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport port-security maximum 2` | כמה כתובות MAC מותרות בפורט. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport port-security mac-address sticky` | לומד את ה-MAC שמחובר עכשיו וזוכר אותו. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`switchport port-security violation shutdown` | מה עושים עם זר: מכבים את הפורט. | [שיעור 2, משימה 3](../lesson-02/) |
| ‎`spanning-tree portfast` | הפורט נהיה ירוק מיד. רק למכשירי קצה: מחשב לא יוצר לולאה. | [שיעור 2, משימה 4](../lesson-02/) |
| ‎`spanning-tree bpduguard enable` | אם מחברים מתג לפורט הזה, הוא נכבה. מגן על PortFast. | [שיעור 2, משימה 4](../lesson-02/) |
| ‎`switchport trunk encapsulation dot1q` | מתג 3560 מכיר שני סוגי תג וצריך לבחור. 2960 מכיר רק dot1q. | [שיעור 2, משימה 4](../lesson-02/) |
| ‎`vtp mode transparent` | המתג הזה שומר רשימה משלו ולא לומד מ-VTP. מתאים למתג שצריך VLAN אחד בלבד. | [שיעור 2, משימה 4](../lesson-02/) |
| ‎`show vtp status` | ‏domain, מצב ומספר גרסה. ה-domain חייב להיות זהה בכולם. | [שיעור 2, משימה 4](../lesson-02/) |
| ‎`show spanning-tree vlan 20` | מי ה-root, ומצב כל פורט: FWD עובד, BLK ממתין. | [שיעור 2, משימה 5](../lesson-02/) |
| ‎`spanning-tree mode pvst` | ‏PVST: עץ נפרד לכל VLAN. | [שיעור 2, משימה 5](../lesson-02/) |
| ‎`spanning-tree vlan 1,10,20,30,40,50 root primary` | הופך את המתג הזה ל-root של ה-VLAN האלה (עדיפות 24576; הנמוך מנצח). | [שיעור 2, משימה 5](../lesson-02/) |
| ‎`spanning-tree guard root` | ‏Root Guard: למתג שמחובר כאן **אסור** להפוך ל-root. | [שיעור 2, משימה 5](../lesson-02/) |
| ‎`spanning-tree vlan 1,10,20,30,40,50 root secondary` | הסגן (עדיפות 28672): root רק אם הראשון נופל. | [שיעור 2, משימה 5](../lesson-02/) |
| ‎`show port-security interface fa0/2` | מצב הפורט, כמה הפרות, וה-MAC האחרון. | [שיעור 2, משימה 7](../lesson-02/) |
| ‎`no shutdown` | מדליק את הפורט. פורטים של נתב כבויים כברירת מחדל. | [שיעור 2, משימה 7](../lesson-02/) |

</div>

| ‎`ipconfig` | מראה את הכתובת, המסכה והשער של המחשב. | [שיעור 3, משימה 5](../lesson-03/) |

| ‎`ip dhcp snooping trust` | מותר לקבל **תשובות** DHCP מהפורט הזה: הוא מוביל לשרת שלנו. כל השאר לא אמינים. | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`show ip dhcp snooping binding` | הטבלה של מי קיבל איזו כתובת, ובאיזה פורט. | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`ipconfig /release` | המחשב מחזיר את הכתובת שלו. | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`ip dhcp excluded-address 192.168.20.1 192.168.20.199` | כתובות שהשרת הזה לא יחלק. | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`ip dhcp pool ROGUE` | יוצר רשימת כתובות לחלוקה. כאן: הרשימה של **התוקף**. | [שיעור 3, משימה 6](../lesson-03/) |

| ‎`default-router 192.168.20.99` | השער שהלקוחות מקבלים (כאן מזויף). | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`dns-server 6.6.6.6` | ה-DNS שהלקוחות מקבלים (כאן מזויף). | [שיעור 3, משימה 6](../lesson-03/) |
| ‎`no ip dhcp snooping trust` | מבטל את האמון: תשובות DHCP מכאן נזרקות שוב. | [שיעור 3, משימה 6](../lesson-03/) |

## פרק 4 — שלושה סניפים ואינטרנט

<div dir="rtl">

| פקודה | מה היא עושה, ולמה | פעם ראשונה |

| ‎`clock rate 2000000` | צד ה-DCE קובע את מהירות הקו הטורי (ביטים בשנייה), והצד השני עוקב. | [שיעור 4, משימה 1](../lesson-04/) |

| ‎`router eigrp 54` | מפעיל EIGRP. המספר (AS) חייב להיות **זהה** בכל נתבי הסניף. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`network 192.168.60.0` | ‏EIGRP עובד בממשק של הרשת הזו, ומפרסם אותה. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`no auto-summary` | מפרסם את הרשתות המדויקות, ולא רשת אחת גדולה ומעוגלת. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`passive-interface g0/0.60` | הרשת מתפרסמת, אבל הודעות ניתוב לא נשלחות למחשבים: אף אחד שם לא יכול להתחזות לנתב. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip route 0.0.0.0 0.0.0.0 200.110.0.1` | מסלול ברירת מחדל: "כל מה שאני לא מכיר, שלח לשם". | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`router bgp 411` | מפעיל BGP עם מספר ה-AS **שלנו**. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`neighbor 200.200.0.2 remote-as 311` | כתובת שכן ה-BGP ומספר ה-AS **שלו**. שני הצדדים חייבים לכתוב. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`network 200.200.0.0 mask 255.255.255.0` | מפרסם לספק את הרשת הציבורית שלנו. המסכה חייבת להיות בדיוק כמו בטבלת הניתוב. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip nat inside source static 192.168.63.1 200.200.0.10` | ‏NAT סטטי: כתובת פנימית אחת ↔ כתובת ציבורית אחת, תמיד. כך העולם מגיע לשרת. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`access-list 1 permit 192.168.60.0 0.0.3.255` | רשימה סטנדרטית: הכתובות שיתורגמו (‎`0.0.3.255` = ארבע רשתות ביחד). | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip nat inside source list 1 interface s0/0/0 overload` | ‏PAT: כל מי שברשימה יוצא עם הכתובת ה**אחת** של הפורט הזה; `overload` מבדיל ביניהם לפי מספרי פורט. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip nat inside` | הפורט הזה בצד של ה**בית**. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip nat outside` | הפורט הזה בצד של ה**אינטרנט**. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip nat pool EILAT-POOL 200.150.0.20 200.150.0.30 netmask 255.255.255.0` | המאגר: מהכתובת הציבורית הראשונה עד האחרונה. | [שיעור 4, משימה 1](../lesson-04/) |
| ‎`ip access-list extended NAT-E` | פותח רשימה לפי שם או מספר, כדי להוסיף או להכניס שורות. | [שיעור 4, משימה 1](../lesson-04/) |
