## מה יהיה לכם בסוף השלב
בבניין A יש שתי רשתות WiFi:
- **‏INTEL-CORP** לעובדים ‏←‏ גישה מלאה, כמו מחשב מחובר בכבל;
- **‏INTEL-GUEST** למבקרים ‏←‏ אינטרנט בלבד, **חסומה** מכל רשת פנימית.

```
   SW-HFA-A-ACC2  Fa0/22 (VLAN 110) ── AP-HFA-A-EMP   ))) "INTEL-CORP"  ── LT-HFA-EMP-01/02
                  Fa0/23 (VLAN 120) ── AP-HFA-A-GUEST ))) "INTEL-GUEST" ── LT-HFA-GUEST-01
```
(‏ACC2 פורט Fa0/22 ‏(VLAN 110) ‏←‏ נקודת הגישה של העובדים "INTEL-CORP" ‏←‏ המחשבים הניידים של העובדים.
פורט Fa0/23 ‏(VLAN 120) ‏←‏ נקודת הגישה של האורחים "INTEL-GUEST" ‏←‏ המחשב הנייד של האורח.)

## חלק 1 — קודם מבינים (בשפה פשוטה)

### 1.1 מה נקודת גישה עושה
**נקודת גישה (Access Point, ‏AP)** היא גשר בין רדיו לכבל: מכשירים אלחוטיים מתחברים אליה, והיא
מעבירה את התעבורה שלהם לרשת הקווית — לתוך **VLAN אחד**. כל AP משדר שם רשת, שנקרא **SSID**.

<div dir="rtl">

| ‎‏SSID | ‎‏AP | פורט במתג | ‎‏VLAN | רשת משנה |
|---|---|---|---|---|
| ‎INTEL-CORP | ‎AP-HFA-A-EMP | ‎ACC2 Fa0/22 | ‎110 WIFI-EMP | ‎10.10.20.0/24 |
| ‎INTEL-GUEST | ‎AP-HFA-A-GUEST | ‎ACC2 Fa0/23 | ‎120 WIFI-GUEST | ‎10.10.21.0/24 |

</div>

ה-VLANים, השערים (HSRP) ומאגרי ה-DHCP של 110 ו-120 קיימים כבר משלבים 02–05 — התכוננו לרגע הזה.

### 1.2 אבטחת WiFi
רדיו עובר דרך קירות — כל מי שעומד בחניון יכול לנסות להתחבר. לכן WiFi חייב להיות **מוצפן** ולדרוש
**מפתח**.

<div dir="rtl">

| אבטחה | איך זה עובד | משתמשים בה עבור |
|---|---|---|
| ‎‏Open | בלי סיסמה, בלי הצפנה | אף פעם |
| ‎‏WEP | הצפנה ישנה, נפרצת תוך דקות | אף פעם |
| ‎**‏WPA2-Personal (PSK)** + AES | סיסמה משותפת אחת לכולם | **אורחים**, ועובדים במעבדה הזו |
| ‎**‏WPA2-Enterprise** | כל משתמש מתחבר עם שם משתמש **אישי** דרך שרת RADIUS ‏(AAA) | עובדים בחברה אמיתית (ראו את האתגר) |

</div>

### 1.3 בידוד אורחים — החלק הכי חשוב
מבקרים צריכים לקבל אינטרנט, אבל **אף פעם** לא להגיע למחשבים או לשרתים שלנו. עושים את זה עם
**ACL על השער של VLAN האורחים** (בשני מתגי ה-distribution): חבילות *מהאורחים* נבדקות ברגע שהן
מגיעות לנתב.

<div dir="rtl">

| כלל (מלמעלה למטה) | למה |
|---|---|
| ‏permit ל-DHCP | כדי שהאורח יוכל לקבל כתובת |
| ‏permit ל-DNS רק לשרת ה-DNS של הספק | כדי ששמות יעבדו |
| **‏deny** לכל דבר שהולך ל-10.x, ‏172.16–31.x, ‏192.168.x | בכלל לא לכתובות פנימיות (פרטיות) |
| ‏permit לכל השאר | = האינטרנט |

</div>

האורחים גם מקבלים מ-DHCP את שרת ה-DNS **של הספק** ‏(200.1.100.10), אף פעם לא את הפנימי שלנו (שלב 05).

זו **ACL מורחבת** (extended): בניגוד ל-ACL הסטנדרטית משלב 07 (רק מקור), היא בודקת מקור **וגם
יעד**, ואפילו את הפרוטוקול/הפורט (‏`udp ... eq domain` = ‏DNS).

## משימה 2 — מציבים ומחברים את שתי נקודות הגישה
🧠 **למה:** כל AP = ‏SSID אחד = ‏VLAN אחד.

👣 **צעדים:**
1. בסרגל המכשירים למטה לחצו **Network Devices** (סמל הנתב) ‏←‏ **Wireless Devices**.
2. גררו **AccessPoint-PT** ליד SW-HFA-A-ACC2. שנו את שמו ל-`AP-HFA-A-EMP` ‏(M4).
3. גררו **AccessPoint-PT** שני ‏←‏ שנו את השם ל-`AP-HFA-A-GUEST`.
4. חברו ב-**Copper Straight-Through** ‏(M5):

<div dir="rtl">

| ‎# | לוחצים קודם על | פורט | לוחצים אחר כך על | פורט |
|---|---|---|---|---|
| ‎1 | ‎AP-HFA-A-EMP | ‎Port 0 | ‎SW-HFA-A-ACC2 | ‎**Fa0/22** |
| ‎2 | ‎AP-HFA-A-GUEST | ‎Port 0 | ‎SW-HFA-A-ACC2 | ‎**Fa0/23** |

</div>

✅ **אמורים לראות:** שני כבלים; אחרי כמה שניות שני הקצוות ירוקים (Fast Forward Time עוזר).

❌ **אם פורט אדום בצד של המתג:** ייתכן ש-Fa0/22–23 עדיין כבויים. התחברו ל-ACC2 ‏←‏
‏`configure terminal` ‏←‏ `interface range fa0/22 - 23` ‏←‏ `no shutdown` ‏←‏ `end`.

🔍 **בודקים עכשיו:** ב-ACC2 ‏`show vlan brief` ‏←‏ ‏Fa0/22 ב-VLAN **‏110**, ‏Fa0/23 ב-VLAN **‏120**.

### 3ב — מחליפים את הכרטיס (עושים את זה ב**כל אחד** מ-3 המחשבים הניידים — תמונות מלאות ב-M8)

5. לחצו שוב על **כפתור ההפעלה** ‏←‏ דולק.

## משימה 8 — ה-ACL לבידוד אורחים ב-A-DIST1 וב-A-DIST2
🧠 **למה בשניהם?** ‏A-DIST2 הוא ה-HSRP **Active** של VLAN 120 — תעבורת האורחים נכנסת דרכו היום.
גם A-DIST1 צריך אותה, ליום ש-A-DIST2 נופל.

### 8א — ב-SWL3-HFA-A-DIST2
👉 **איפה:** ‏A-DIST2 ‏←‏ CLI ‏←‏ נכנסים `admin` / `Intel#Adm1n` ‏←‏ `SWL3-HFA-A-DIST2#`‎.

⌨️ מקלידים — קודם את הרשימה:
```
configure terminal
ip access-list extended GUEST-IN
 remark --- DHCP requests to the gateway ---
 permit udp any any eq bootps
 remark --- DNS only to the ISP resolver ---
 permit udp any host 200.1.100.10 eq domain
 remark --- nothing internal (all private ranges) ---
 deny ip any 10.0.0.0 0.255.255.255
 deny ip any 172.16.0.0 0.15.255.255
 deny ip any 192.168.0.0 0.0.255.255
 remark --- everything else = the internet ---
 permit ip any any
 exit
```
🔍 **בודקים עכשיו:** ‏`do show access-lists GUEST-IN` ‏←‏ ‏6 שורות ממוספרות (10, ‏20, ‏30…) בסדר הזה:
‏bootps, ‏domain, שלוש שורות deny, ‏permit ip any any.

❌ **אם שורה במקום הלא נכון:** ‏`no ip access-list extended GUEST-IN` והקלידו את כל הרשימה שוב.

⌨️ אחר כך מחילים אותה על השער של VLAN האורחים, **in**:
```
interface vlan 120
 ip access-group GUEST-IN in
 end
copy running-config startup-config
```

<div dir="rtl">

| פקודה | בשפה פשוטה |
|---|---|
| ‎`ip access-list extended GUEST-IN` | רשימת כללים מפורטת (מקור + יעד + פרוטוקול) בשם GUEST-IN |
| ‎`permit udp any any eq bootps` | "התר בקשות DHCP" (‏bootps = פורט שרת ה-DHCP, ‏67) |
| ‎`permit udp any host 200.1.100.10 eq domain` | "התר DNS ‏(פורט 53) רק לשרת האחד הזה" |
| ‎`deny ip any 10.0.0.0 0.255.255.255` | "חסום כל דבר שהולך לכתובת 10.x כלשהי" |
| ‎`permit ip any any` | "התר את השאר" (בלעדיה ה-deny הבלתי נראה בסוף היה חוסם גם את האינטרנט) |
| ‎`ip access-group GUEST-IN in` | "בדוק עם הרשימה הזו חבילות ש**נכנסות** מ-VLAN האורחים" |

</div>

### 8ב — ב-SWL3-HFA-A-DIST1
👉 **איפה:** ‏A-DIST1 ‏←‏ CLI ‏←‏ נכנסים ‏←‏ `SWL3-HFA-A-DIST1#`‎.

⌨️ מקלידים את **אותם שני בלוקים** (בדיוק כמו ב-8א):
```
configure terminal
ip access-list extended GUEST-IN
 remark --- DHCP requests to the gateway ---
 permit udp any any eq bootps
 remark --- DNS only to the ISP resolver ---
 permit udp any host 200.1.100.10 eq domain
 remark --- nothing internal (all private ranges) ---
 deny ip any 10.0.0.0 0.255.255.255
 deny ip any 172.16.0.0 0.15.255.255
 deny ip any 192.168.0.0 0.0.255.255
 remark --- everything else = the internet ---
 permit ip any any
 exit
interface vlan 120
 ip access-group GUEST-IN in
 end
copy running-config startup-config
```
🔍 **בודקים עכשיו:** ‏`show running-config interface vlan 120` ‏←‏ השורה
‏`ip access-group GUEST-IN in` נמצאת שם.

## 🎓 מסבירים לבוחן

בבחינה, הבוחן מצביע על הפרויקט **שלכם** ומבקש **להסביר** ו**להראות**. תרגלו כל שאלה
**בקול**, ואז הראו את התשובה בפרויקט שלכם — לא בדוגמה. כסו את התשובה, ענו בעצמכם, ורק אז
פתחו והשוו.

★1–★3 = שאלה ממאגר השאלות של משרד החינוך (רמת קושי 1–3).
◆ = לא במאגר, אבל בוחנים שואלים אותה לעיתים קרובות.

**1. ★3 כיצד ניתן להשתמש ב-ACL כדי לאפשר לחלק מהמחשבים להתחבר ולחסום גישה לאחרים?**

<details dir="rtl"><summary>תשובה</summary>

‏ACL מורחבת על השער של VLAN האורחים: ‏deny מרשת האורחים לבלוקים הפנימיים, ואחר כך permit לכל
השאר (האינטרנט). מוחלת `in` על ה-SVI של האורחים (‏`ip access-group GUEST-IN in`). זו ה-ACL לבידוד
אורחים של השלב הזה.

**איפה מראים:** `show access-lists GUEST-IN`, `show running-config interface vlan <guest>`‎
</details>

**2. ◆ מהו SSID? למה שני SSIDs?**

<details dir="rtl"><summary>תשובה</summary>

השם של רשת אלחוטית. כל SSID ממופה ל-VLAN משלו — עובדים ל-VLAN העובדים, אורחים ל-VLAN האורחים —
כך שהאורחים מופרדים מהחברה (דרישה 18).

**איפה מראים:** ‏AP ‏←‏ Config ‏←‏ Wireless
</details>

**3. ◆ מה ההבדל בין WPA2-Personal ‏(PSK) ל-WPA2-Enterprise?**

<details dir="rtl"><summary>תשובה</summary>

‏Personal: כולם חולקים סיסמה אחת. ‏Enterprise: כל משתמש מתחבר עם שם משתמש וסיסמה משלו, שנבדקים
בשרת RADIUS — עובד שעוזב פשוט מושבת.

**איפה מראים:** ‏AP ‏←‏ Config ‏←‏ Wireless ‏←‏ Authentication
</details>

## 👩‍🏫 הערות למורה
- **מערך שיעור (כ-90 דקות):** ‏15 דק' מיפוי AP/SSID/VLAN + טבלת אבטחת ה-WiFi ‏←‏ 15 דק' הסיפור של
  בידוד אורחים ("מבקר בלובי שסורק את הרשת שלכם") ‏←‏ 30 דק' בנייה (החלפת הכרטיס במחשב הנייד לוקחת
  זמן בפעם הראשונה) ‏←‏ 15 דק' ‏ACL ‏←‏ 15 דק' בדיקות.
- **שאלות נפוצות של תלמידים**
  - *"למה לא AP אחד עם שני SSIDs?"* — נקודות גישה אמיתיות עושות את זה (‏SSID אחד לכל VLAN על פורט
    trunk). ה-AccessPoint-PT הפשוט של PT תומך ב-SSID אחד לכל AP, ולכן משתמשים בשניים.
  - *"למה `in` ולא `out`?"* — ‏`in` על VLAN 120 = חבילות מהאורחים, שמסוננות בנתב הראשון שהן פוגשות.
- **טעויות אופייניות:** שכחה להחליף לכרטיס WPC300N; ‏ACL רק על DIST אחד; סדר השורות ב-ACL המורחבת.
